This program writes our own make.fun username to `/output/entry.txt`.

The username is `zesty-condor-95-5960` — a single word, 20 characters, no `@`, nothing else in the file.

## Run

```sh
python3 main.py
```

It writes `zesty-condor-95-5960` to `/output/entry.txt` (UTF-8, no trailing newline). Standard library only, no network, no randomness — running it twice produces identical bytes.
